# The Ortus Outreach — Installer

LinkedIn outreach automation for The Ortus Club. macOS only.

**Latest release:** [Releases page](https://github.com/ortusclub/ortus-outreach-installer/releases/latest)

## Direct download

- Apple Silicon (M1/M2/M3/M4): https://github.com/ortusclub/ortus-outreach-installer/releases/latest/download/Ortus-Outreach-arm64.dmg
- Intel Mac: https://github.com/ortusclub/ortus-outreach-installer/releases/latest/download/Ortus-Outreach-intel.dmg

## Install

1. Open the DMG.
2. Drag **The Ortus Outreach** onto the Applications shortcut.
3. Right-click **Ortus Outreach Setup** → Open → Open. This is a one-time Gatekeeper bypass for the unsigned app.
4. The Ortus icon appears in your menu bar (top-right). Click → Show Dashboard.

If macOS still blocks the app: **System Settings → Privacy & Security** → click "Open Anyway".
