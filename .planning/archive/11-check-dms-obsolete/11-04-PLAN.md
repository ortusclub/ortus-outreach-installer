<objective>
Wave 2 UI — Build the Check DMs button, the Replies panel, and the polling/rendering JS. Produce a pure renderer module (`replies-panel.mjs`) that both the app AND the Wave 0 UI tests can import. Convert `public/js/app.js` to an ES module so the renderer can be imported directly, eliminating the `window.renderRepliesPanel` / `setTimeout(500)` race condition that the previous plan carried.

Purpose: Plan 02 built the module; Plan 03 exposed it over HTTP; this plan gives the operator a button to press and a panel to read. Security-critical: reply snippets come from LinkedIn and MUST be rendered via `textContent` — never `innerHTML` — because participants can submit any text including `<script>` tags.

**Key revision (checker blocker: key_links_planned, load-order race):** the previous plan wired the Replies panel via a `window.renderRepliesPanel` global with a `setTimeout(500)` fallback, because a `<script type=module>` shim is deferred while the classic `<script src=app.js>` is not — meaning `pollCheckDmsStatus` could resolve BEFORE the ESM module executed. The revision eliminates the race entirely by promoting `app.js` itself to a module, importing the renderer directly, and re-exposing HTML-inline-referenced functions to `window` so existing onclick handlers keep working.

Output:
- New `public/js/replies-panel.mjs` — pure DOM render function (importable by tests)
- Extended `public/index.html` — button in Campaign section; Replies panel markup placed BETWEEN #nav-status and #history-section (structurally asserted); `<script src=js/app.js>` becomes `<script type=module src=/js/app.js>`
- Extended `public/js/app.js` — converted to ESM, direct import of renderer, `startCheckDms` + polling, `window.<fnName> = <fnName>` re-exposure block at end for all 35 HTML-inline-referenced functions
- Extended `public/css/style.css` — monochrome command-deck styles for the panel
- Wave 0 UI tests in `tests/ui/*.test.js` flip RED → GREEN
- DMS-06 is structurally satisfied (plain `<a target="_blank">` + existing `setWindowOpenHandler`) — manual verification in Plan 05
</objective>

Why module conversion is the preferred fix (per checker directive):
- A `<script type=module>` shim alongside a classic `<script src=app.js>` is a deferred-vs-not race: the module executes AFTER DOMContentLoaded's `load` event, but the classic script can fire synchronously on parse. `pollCheckDmsStatus` can be invoked via `setInterval(2000)` before the module sets `window.renderRepliesPanel`.
- The `setTimeout(500)` fallback in the previous plan is not a fix — it is a 500ms band-aid that fails on slow Electron startup.
- By promoting app.js itself to a module, the import is resolved before any function in app.js runs. No race, no fallback needed.

- Cost: +1 task (Task 4 — the ESM conversion and window re-exposure). Plan 11-04 grows from 3 tasks / ~250 lines of action to 4 tasks / ~320 lines of action. Still well under the 50% context target.

    ```javascript
    // public/js/replies-panel.mjs — Phase 11 Check DMs renderer.
    // Pure DOM logic — importable by the Wave 0 UI test suite via stub document,
    // and imported DIRECTLY by app.js (which is also an ES module after Plan 11-04 Task 4).
    // No window globals, no setTimeout fallback — direct ESM import resolves before any polling fires.

    export function formatRelative(iso) {
      if (!iso) return '';
      const ms = Date.now() - new Date(iso).getTime();
      if (!Number.isFinite(ms)) return '';
      if (ms < 60_000) return 'just now';
      if (ms < 3_600_000) return `${Math.round(ms / 60_000)}m ago`;
      if (ms < 86_400_000) return `${Math.round(ms / 3_600_000)}h ago`;
      return `${Math.round(ms / 86_400_000)}d ago`;
    }

    export function renderRepliesPanel(replies, errors) {
      const section = document.getElementById('nav-replies');
      if (section) section.style.display = '';

      const countEl = document.getElementById('replies-count');
      if (countEl) countEl.textContent = (replies && replies.length) ? ` (${replies.length})` : '';

      // Error tile FIRST — Pitfall 6 (operator must see failures)
      const errBox = document.getElementById('replies-errors');
      if (errBox) {
        errBox.innerHTML = '';  // safe — we control the content
        if (errors && errors.length) {
          const div = document.createElement('div');
          div.className = 'reply-error';
          div.textContent = `Check DMs hit ${errors.length} error(s). Retry in 10–15 min. Watermark NOT advanced.`;
          errBox.appendChild(div);
        }
      }

      const list = document.getElementById('replies-list');
      if (!list) return;
      list.innerHTML = '';

      if ((!replies || !replies.length) && (!errors || !errors.length)) {
        const p = document.createElement('p');
        p.className = 'empty-state';
        p.textContent = 'No new replies.';
        list.appendChild(p);
        return;
      }

      for (const r of (replies || [])) {
        const row = document.createElement('div');
        row.className = 'reply-row' + (r.ambiguous ? ' reply-ambiguous' : '');

        const name = document.createElement('div');
        name.className = 'reply-name';
        name.textContent = `${r.firstName || ''} ${r.lastName || ''}`.trim() + (r.ambiguous ? ' — ambiguous' : '');

        const snippet = document.createElement('div');
        snippet.className = 'reply-snippet';
        snippet.textContent = r.snippet || '';   // CRITICAL: textContent, not innerHTML

        const meta = document.createElement('div');
        meta.className = 'reply-meta';
        meta.textContent = `${formatRelative(r.timestamp)} • ${r.profileName || ''}`;

        const actions = document.createElement('div');
        actions.className = 'reply-actions';
        if (r.threadId) {
          const a = document.createElement('a');
          a.className = 'btn btn-secondary btn-sm';
          a.href = `https://www.linkedin.com/messaging/thread/${r.threadId}/`;
          a.target = '_blank';
          a.rel = 'noopener noreferrer';
          a.textContent = 'Open Thread';
          actions.appendChild(a);
        }

        row.appendChild(name);
        row.appendChild(snippet);
        row.appendChild(meta);
        row.appendChild(actions);
        list.appendChild(row);
      }
    }
    ```
