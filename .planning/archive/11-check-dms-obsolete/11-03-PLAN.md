<objective>
Wave 2 — Expose the Check DMs module over HTTP and finalize the Google Sheet writeback surface area by extending Apps Script config.

Purpose: Plan 02 built the module in isolation. This plan wires it to the outside world via three Express endpoints (matching the existing `/api/campaign/*` pattern) AND extends the Apps Script config so `ensureTrackingColumns` auto-creates the Reply / Reply At / Reply Preview columns on first run. Both changes are additive and independent of UI — they run in parallel with Plan 04.

- `POST /api/check-dms/start` — launches scan with mutex against campaign
- `POST /api/check-dms/stop` — aborts mid-scan
- `GET /api/check-dms/status` — polled every 2s by the UI
- `GET /api/check-dms/replies` — fetched once when scan completes
- Symmetric guard on `/api/campaign/start` (refuse when `checkDms.running`)
- `google-apps-script.js` TRACKING_COLUMNS + FIELD_MAP extended
</objective>

       app.post('/api/check-dms/start', (req, res) => {
         try {
           // Mutex — RESEARCH.md §Pitfall 5
           if (campaign.running) {
             return res.status(409).json({ error: 'Cannot check DMs while a campaign is running' });
           }
           if (checkDms.running) {

           }
           const { profileIds, sheetUrl, linkedinColumn } = req.body || {};
           if (!Array.isArray(profileIds) || profileIds.length === 0) {
             return res.status(400).json({ error: 'profileIds required' });
           }
           if (!sheetUrl) {
             return res.status(400).json({ error: 'sheetUrl required' });
           }

           const owner = req.user;
           startCheckDms({ profileIds, sheetUrl, linkedinColumn: linkedinColumn || '' })
             .then(() => {
               const s = getCheckDmsStatus();
               const replies = getCheckDmsReplies();
               notifyEmail(owner, {
                 title: 'Check DMs finished',
                 body: `Found ${replies.length} reply(ies). ${(s.errors || []).length} error(s).`,
                 link: '/',
               }).catch(() => {});
             })
             .catch(err => {
               console.error('Check DMs error:', err.message);
               notifyEmail(owner, {
                 title: 'Check DMs failed',
                 body: err.message,
                 link: '/',
               }).catch(() => {});
             });

           res.json({ ok: true, message: 'Check DMs started' });
         } catch (err) {
           console.error('Check DMs start error:', err.message);
           res.status(500).json({ error: err.message });
         }
       });

       app.post('/api/check-dms/stop', (_req, res) => {
         try {
           stopCheckDms();
           res.json({ ok: true });
         } catch (err) {
           res.status(500).json({ error: err.message });
         }
       });

       app.get('/api/check-dms/status', (_req, res) => {
         res.json(getCheckDmsStatus());
       });

       app.get('/api/check-dms/replies', (_req, res) => {
         res.json({ replies: getCheckDmsReplies() });
       });
