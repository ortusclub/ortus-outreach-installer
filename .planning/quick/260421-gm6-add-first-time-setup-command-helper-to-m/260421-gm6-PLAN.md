  <name>Task 1: Create executable First-Time Setup.command helper</name>
  <files>build/First-Time Setup.command</files>
  <action>
Create `build/First-Time Setup.command` with the following bash content (keep under 25 lines, one clear purpose — strip quarantine and launch):

```bash
#!/bin/bash
# First-Time Setup for The Ortus Outreach
# Strips macOS quarantine flag and launches the app.
# Required once because the app is unsigned (no Apple Developer cert).

APP_PATH="/Applications/The Ortus Outreach.app"

if [ ! -d "$APP_PATH" ]; then
  /usr/bin/osascript -e 'display dialog "Please drag The Ortus Outreach to your Applications folder first, then run First-Time Setup again." buttons {"OK"} default button "OK" with icon caution with title "Ortus Outreach Setup"'
  exit 1
fi

/usr/bin/xattr -cr "$APP_PATH"
/usr/bin/open "$APP_PATH"
exit 0
```

After writing, make the file executable:
```bash
chmod +x "build/First-Time Setup.command"
```

Rationale:
- `xattr -cr` clears ALL extended attributes recursively (including `com.apple.quarantine`), which is what unblocks Gatekeeper.
- `osascript` dialog handles the edge case where the teammate runs the helper before dragging the app (no silent failure).
- No heredocs, no argument parsing, no logging — simplest script that solves the problem (per task brief).
- The executable bit must be set in git so the file stays executable when other teammates clone the repo and build the DMG; electron-builder preserves file mode when copying into the DMG.

After `chmod +x`, stage the file with explicit mode preservation:
```bash
git update-index --chmod=+x "build/First-Time Setup.command"
```
(Run this after `git add` but before committing in the final task step.)
