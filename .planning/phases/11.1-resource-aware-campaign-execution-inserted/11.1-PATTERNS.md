**Analog 2:** `src/campaign.js:56-72` — `checkHostHealth` already uses `os.freemem/totalmem/loadavg/cpus`. Refactor to a **pure returner of numerics**, not of warnings:

**Current shape** (`src/campaign.js:56-72`):
```javascript
function checkHostHealth() {
  const warnings = [];
  const GB = 1024 * 1024 * 1024;
  const freeGB = os.freemem() / GB;
  const totalGB = os.totalmem() / GB;
  const load1 = os.loadavg()[0];
  const cpuCount = os.cpus().length;
  const loadThreshold = cpuCount * 0.8;

  if (freeGB < 2) {
    warnings.push(`Free RAM is ${freeGB.toFixed(1)}GB / ${totalGB.toFixed(1)}GB total — low.`);
  }
  if (load1 > loadThreshold) {
    warnings.push(`1-min load average ${load1.toFixed(2)} exceeds ${loadThreshold.toFixed(2)} (${cpuCount} CPUs × 0.8).`);
  }
  return { ok: warnings.length === 0, warnings };
}
```

### `src/campaign.js` — per-iteration throttle + parking + delay composition (lines 845-882)

**Analog:** self (same file, same block). This is the only existing delay code.

**Current delay block** (`src/campaign.js:845-869`):
```javascript
// Delay between leads + session breaks (interruptible by abort)
if (!campaign._abort) {
  const isMessageMode = mode === 'message_only';
  const delayMultiplier = (!isMessageMode && profileIds.length === 1) ? 2.0 : 1.0;

  const SESSION_BREAK_EVERY = 15;
  let waitMs;
  if (!isMessageMode && totalDone > 0 && totalDone % SESSION_BREAK_EVERY === 0) {
    const breakMin = 10 * 60 * 1000;
    const breakMax = 20 * 60 * 1000;
    waitMs = Math.floor(Math.random() * (breakMax - breakMin + 1) + breakMin);
    log(`  ☕ Session break: ${(waitMs / 60000).toFixed(0)} min (${totalDone} leads processed across all accounts)`);
  } else if (isMessageMode) {
    waitMs = Math.floor(Math.random() * (delayMax - delayMin + 1) + delayMin) * 1000;
    log(`  ⏳ ${(waitMs / 1000).toFixed(0)}s (message gap)`);
  } else {
    waitMs = Math.floor(Math.random() * (delayMax - delayMin + 1) + delayMin) * 1000;
    waitMs = Math.floor(waitMs * delayMultiplier);
    if (delayMultiplier > 1) log(`  ⏳ ${(waitMs / 1000).toFixed(0)}s (single-account: ${delayMultiplier}x slower)`);
    else log(`  ⏳ ${(waitMs / 1000).toFixed(0)}s`);
  }
```

**Target (RESEARCH.md §Pattern 3):**
- Replace line 851 with `singleProfileMult * throttleMult` composition.
- Apply `throttleMult` ONLY inside the `else` branch (lines 864-869). Session-break and message-mode branches stay byte-identical (D-09 / Pitfall 6).
- Insert `await parkProfile(page)` call **before** the `if (!campaign._abort)` guard at line 845 (or immediately after performOutreach completes around line 845), so parking happens regardless of delay branch.
- Insert throttle re-evaluation at start of each iteration (top of `while (!campaign._abort)` loop at line 531).

**Log format pattern** (`src/campaign.js:132-137`) — use `log()` not `console.log()`:
