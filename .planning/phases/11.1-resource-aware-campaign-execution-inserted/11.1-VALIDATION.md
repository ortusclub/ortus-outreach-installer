## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| Dashboard tile color transitions (ink → amber → red) | Success Criteria 1 | Visual CSS behavior | Run campaign, watch header tiles while RAM rises; verify color change at configured thresholds |
| Slow-mode banner appears/disappears | Success Criteria 4 | DOM rendering under live data | Force RAM above threshold (e.g. open memory-heavy tab), observe banner; let RAM fall, observe banner disappear |
| Profile parking on about:blank between leads | Success Criteria 2 | Requires live GoLogin profile + LinkedIn session | Run campaign with 2+ leads per profile; in a GoLogin window, verify each profile navigates to about:blank between actions and returns to LinkedIn without re-login |
| Session preservation across parking | Success Criteria 2 | Requires LinkedIn session cookie behavior | After 5+ park cycles, confirm LinkedIn does not prompt re-auth |
| Per-Chromium RSS aggregation on Windows | Cross-platform behavior | Requires Windows host | Run campaign on Windows colleague machine; confirm `browsers` count and RSS values match Task Manager's Chrome entries |
| CPU fallback on Windows (`os.loadavg()` returns 0,0,0) | D-05/D-06 on Windows | OS-specific API gap | On Windows host, verify CPU % derives from `os.cpus()` delta, not loadavg |
