## Decisions Made

- **Refactor checkHostHealth: deferred.** The plan's Edit B2 allowed keeping the sync body byte-identical rather than delegating to async `rmSample([])`. Chose byte-identical because the caller is sync and async refactor would ripple into startCampaign. Same host-health warnings; same call site at campaign.js:304-308. Plan 02 will introduce the live per-iteration sampler that supersedes this preflight.
- **npm test script glob.** Used `node --test tests/*.test.js` (shell glob) instead of the plan's `node --test tests/`. Node 25 rejects bare-directory with `MODULE_NOT_FOUND: tests` — see Deviation 1. Glob is semantically equivalent and cross-version safe.
