## Established conventions this phase inherits

- **Env-knob config with code defaults** — `PROFILE_CLOSE_GAP_MIN` follows the `RAM_THROTTLE_PCT` / `IDLE_PARKING_ENABLED` idiom: `Number(process.env.X) || default`. Document in `.env.example` under a Phase 11.2 comment block (matches the Phase 11.1 block at the bottom of the file).
- **`node:test` + `node:assert/strict`** — no Jest/Mocha. `npm test` glob (`tests/*.test.js`) already wired in Phase 11.1.
- **Error-swallow at boundaries** — `pidusage` errors → `browsers: []`; `parkProfile` errors → log + continue; `osascript` errors → silent (per D-16). All 11.2 new code follows this.
- **Test hooks with underscore prefix** — Plan 01 exposes `_setExecFile(fn)` on `src/mac-window.js` for tests. Matches `_resetSampleCache` / `_setTestState` convention.
- **Wrap-don't-touch core logic** — `performOutreach`, LinkedIn actions, GoLogin SDK internals, sheet read/write, retry logic, mode routing — all byte-identical after 11.2. Refactor happens in the `startCampaign` orchestrator body only.
- **Fire-and-forget for non-critical side effects** — AppleScript minimize wrapped in `.catch(()=>{})` at call site (and internally tolerant). Same as Sheet writes: `.catch(() => {})` at the call-site in `src/campaign.js:804`.

## Module boundaries (who owns what)

| Boundary | Owner | Consumers |
|----------|-------|-----------|
| `isDarwin` detection | `src/mac-window.js` (module-level constant) | Its own exported functions only; never surfaced outside. |
| osascript invocation | `src/mac-window.js` exclusively | gologin-launcher + local-launcher + server `/api/browsers/show` endpoint — all through the two exported functions, never direct execFile calls in campaign or server code. |
| PID→window mapping | `src/gologin-launcher.js` (`getProfilePid`, `getActiveBrowserPids` — both Phase 11.1, reused) | mac-window.js is fed PIDs; it does not know about profileIds. |
| Batch-of-5 constant | `src/campaign.js` (module-level `BATCH_SIZE = 5`) | No one else — private to campaign loop. Not exposed via API. Not configurable from UI (D-01). |
| `PROFILE_CLOSE_GAP_MIN` env | Read once in `src/campaign.js` at import/loadConfig time, defaulted to 15 | Consumed inline in the close-decision branch. |
| Tray & dock lifecycle | `electron/main.js` exclusively | No ipcRenderer dependency for Show Browsers — tray menu item calls `fetch()` against the local server (matches the renderer path so both entry points share code). |
