# Phase 11.2 Plan 01: Mac Window Minimize Primitive Summary

## Decisions Made

- **TDD split into two commits** for Task 1 — RED (test file alone, intentionally failing) and GREEN (implementation) — preserves the classic TDD trail in git log so a future reviewer can verify the test was written first.
- **3s timeout for minimize, 2s for unminimize** — the minimize path runs a 10×0.1s repeat-until-window loop (max ~1s) plus the actual minimize call; 3s gives a 2s headroom. Unminimize is a single invocation — 2s is ample.
- **Numeric-only PID interpolation** via `coercePid` (`Number(x)` + finite + positive guard + `Math.trunc`) makes osascript injection structurally impossible: even if an untrusted string ever reached the function, it would short-circuit to `return` before the script is built.
- **Platform no-op semantics** — on non-darwin, `minimizeByPid` returns immediately (Promise resolves with `undefined`); `unminimizeByPids` returns `{ minimized: 0, skipped: 0 }`. The server endpoint short-circuits with `platform: 'other'` for clarity rather than relying only on the helper's implicit no-op.
