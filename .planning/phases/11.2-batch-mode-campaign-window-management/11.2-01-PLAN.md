AppleScript template (verified syntax, RESEARCH §Pattern 1 + §Example 1):

```applescript
tell application "System Events"
  repeat 10 times
    if (count of windows of (first process whose unix id is <N>)) > 0 then exit repeat
    delay 0.1
  end repeat
  set miniaturized of every window of (first process whose unix id is <N>) to true
end tell
```

`<N>` is `Number(pid)` interpolated once — there is NO untrusted-string interpolation. Shell injection is impossible because `execFile` is used (not `exec`), and the argv is `['-e', script]`.

**Implementation (`src/mac-window.js`) — after tests are RED:**

```javascript
/**
 * macOS AppleScript wrapper — minimize/un-minimize Chromium windows by PID.
 * Phase 11.2 (D-16, D-18). Best-effort: swallows errors, no-op on non-darwin.
 * See .planning/phases/11.2.../11.2-RESEARCH.md §Pattern 1 + §Pitfall 1.
 */
import { execFile as execFileCb } from 'node:child_process';
import { promisify } from 'node:util';

const isDarwin = process.platform === 'darwin';
const realExecFile = promisify(execFileCb);

// Module-level indirection so tests can inject a mock. See _setExecFile.
let _execFile = realExecFile;

export function _setExecFile(fn) {
  _execFile = fn ?? realExecFile;
}

function coercePid(pid) {
  const n = Number(pid);
  if (!Number.isFinite(n) || n <= 0) return null;
  return Math.trunc(n);
}

export async function minimizeByPid(pid) {
  if (!isDarwin) return;
  const n = coercePid(pid);
  if (!n) return;
  // repeat-until-window loop handles the compositor race (RESEARCH §Pitfall 1).
  const script = `
    tell application "System Events"
      repeat 10 times
        if (count of windows of (first process whose unix id is ${n})) > 0 then exit repeat
        delay 0.1
      end repeat
      set miniaturized of every window of (first process whose unix id is ${n}) to true
    end tell
  `.trim();
  try {
    await _execFile('/usr/bin/osascript', ['-e', script], { timeout: 3000 });
  } catch { /* best-effort */ }
}

export async function unminimizeByPids(pids) {
  if (!isDarwin) return { minimized: 0, skipped: 0 };
  let minimized = 0;
  let skipped = 0;
  for (const pid of pids || []) {
    const n = coercePid(pid);
    if (!n) { skipped++; continue; }
    const script =
      `tell application "System Events" to ` +
      `set miniaturized of every window of (first process whose unix id is ${n}) to false`;
    try {
      await _execFile('/usr/bin/osascript', ['-e', script], { timeout: 2000 });
      minimized++;
    } catch {
      skipped++;
    }
  }
  return { minimized, skipped };
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Node process → osascript (`/usr/bin/osascript`) | Subprocess boundary. Our argv is `['-e', script]` where script is a static template with one numeric PID slot. |
| Browser → server (POST /api/browsers/show) | Existing session-gate middleware applies. No body, no query params, no user-provided data enters the osascript path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.2-01 | Tampering (shell/osascript injection) | `minimizeByPid` / `unminimizeByPids` | mitigate | `coercePid()` coerces with `Number(x)`, rejects non-finite / non-positive. `execFile` (not `exec`) — no shell interpretation. Script is a static template; only numeric PIDs interpolate. Tests explicitly assert bogus pids are no-ops (Task 1 test list). |
| T-11.2-02 | Denial of Service (hung osascript) | `minimizeByPid` | mitigate | 3s timeout on execFile; 2s timeout on unminimize path. Errors swallowed so a hung System Events can't stall the launch or endpoint. |
