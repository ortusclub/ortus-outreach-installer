  <action>
1. Import `checkProfileDms` from `./src/linkedin/check-dms.js` at top of server.js.
2. Add a module-level `checkDms = { running: false, _abort: false, currentProfile: null, repliesFound: 0, errors: [], startedAt: null, _lastResults: null }` near where `campaign` lives (search for `campaign.running`).
3. Add `POST /api/check-dms/start` endpoint that:
   - Returns 409 if `campaign.running` or `checkDms.running`
   - Validates body: `{ profileIds, sheetUrl, linkedinColumn }`
   - Sets `checkDms.running = true`, `checkDms.startedAt = Date.now()`, `checkDms._abort = false`
   - Dispatches fire-and-forget:
     ```js
     (async () => {
       try {
         for (const profileId of profileIds) {
           if (checkDms._abort) break;
           checkDms.currentProfile = profileId;
           const result = await checkProfileDms(profileId, { sheetUrl, linkedinColumn, ... });
           // aggregate
         }
         checkDms._lastResults = { byProfile, completedAt: Date.now() };
       } finally {
         checkDms.running = false;
         checkDms.currentProfile = null;
       }
     })();
     ```
   - Responds 202 with `{ started: true }`.
4. **Mutex guard on /api/campaign/start** (server.js:381): Add 2 lines at the top:
   ```js
   if (checkDms.running) return res.status(409).json({ error: 'Check DMs is running — stop it first' });
   ```

**Preservation check:** `git diff server.js` — only additions + the 2-line mutex guard. No other endpoint's body changes.
  </action>
