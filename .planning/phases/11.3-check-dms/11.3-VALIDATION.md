## Sampling Rate

After every task commit, the executor MUST:

1. Run `npm test` — confirm baseline + new tests
2. Check `git diff HEAD` — verify only intended files changed
3. For Plan 11.3-04 (UI): additionally run the 15-item smoke-test checklist from `11.3-CONTEXT.md` <preservation_contract>

## Failure handling

- **RED test fails after Wave 1 commits:** the implementation diverged from a fixture. Fix implementation (fixture is authoritative).
- **15-item smoke test fails after Plan 11.3-04:** STOP. Revert the app.js conversion commit. Investigate. Don't try to patch forward.
- **Manual E2E fails at any step:** route fix through /gsd-quick. Do not skip.
