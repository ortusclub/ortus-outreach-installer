<task type="auto">

  <action>
In public/js/app.js, add the following functions before the Init section (before `loadProfiles();` around line 336).

Per D-03, wire to existing API endpoints. Per D-04, populate ALL relevant textareas on load.

Add these functions:

1. `async function fetchTemplateList()` — calls `GET /api/templates`, populates the `#tpl-select` dropdown with an option for each template name. Preserve the first "-- Select a template --" option. Use `escHtml()` for template names in option text.

2. `async function loadSelectedTemplate()` — reads `#tpl-select` value. If empty, alert "Select a template first." Otherwise, fetch `GET /api/templates`, find the selected template object, and populate:
   - `#tpl-note` textarea with `connectionNote`
   - `#tpl-followup` textarea with `followUp1`
   - `#tpl-inmail-subject` input with `inmailSubject`
   - `#tpl-inmail-body` textarea with `inmailBody`
   Per D-04: all four fields must be populated from saved data.

3. `async function saveCurrentTemplate()` — prompts user for a name via `prompt('Template name:')`. If null/empty, return. Gathers current values from the four template fields (tpl-note, tpl-followup, tpl-inmail-subject, tpl-inmail-body) into `{ connectionNote, followUp1, inmailSubject, inmailBody }`. POSTs to `/api/templates` with `{ name, templates }`. On success, calls `fetchTemplateList()` to refresh dropdown and sets dropdown value to the new name.

4. `async function deleteSelectedTemplate()` — reads `#tpl-select` value. If empty, alert "Select a template first." Otherwise, confirms via `confirm('Delete template "' + name + '"?')`. Calls `DELETE /api/templates/${encodeURIComponent(name)}`. On success, calls `fetchTemplateList()` to refresh dropdown.

In the Init section, add `fetchTemplateList();` call after existing `loadProfiles();` so templates load on page open.
