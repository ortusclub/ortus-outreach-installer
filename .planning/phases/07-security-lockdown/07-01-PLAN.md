**In server.js** (per D-04, D-06):

1. Remove lines 3-13 entirely (the two `if (!process.env.X)` blocks that set hardcoded fallback values for GOLOGIN_API_TOKEN and SHEETS_WEBAPP_URL).

2. After the `import 'dotenv/config';` line (line 1) and before the other imports, add a startup validation block:

```javascript
// ── Startup env validation (D-06) ──────────────────────────────────
const REQUIRED_ENV = ['GOLOGIN_API_TOKEN', 'SHEETS_WEBAPP_URL', 'DASHBOARD_USER', 'DASHBOARD_PASS'];
const missing = REQUIRED_ENV.filter(k => !process.env[k]);
if (missing.length) {
  console.error(`\n  FATAL: Missing required environment variables:\n${missing.map(k => '    - ' + k).join('\n')}\n\n  Copy .env.example to .env and fill in all values.\n`);
  process.exit(1);
}
```

3. Keep everything else in server.js unchanged -- all Express routes, middleware, imports stay as-is.

**In src/campaign.js** (per D-04 -- minimal non-breaking change):

1. Change the `getToken()` function at line 104-106 from:
```javascript
function getToken() {
  return process.env.GOLOGIN_TOKEN || 'eyJhbGci...hardcoded...';
}
```
to:
```javascript
function getToken() {
  return process.env.GOLOGIN_API_TOKEN;
}
```
This standardizes on GOLOGIN_API_TOKEN (matching server.js and .env.example) and removes the hardcoded fallback. The startup validation in server.js guarantees this var is set before campaign.js ever calls getToken().
