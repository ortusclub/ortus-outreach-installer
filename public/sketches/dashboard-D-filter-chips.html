FIX 1 — STATUS IS A COLUMN

Status is a pill column on every row, never ambiguous. Monitoring appears next to Active in mixed views — they're never confused.

FIX 2 — SELECT ACROSS STATES

"Select all" picks every visible row regardless of status. Want to nuke 30 old past campaigns + 2 broken drafts in one shot? Three clicks: filter chips → select all → delete.

TRADE-OFF

One unified list is the densest layout — easiest to bulk-edit, but you have to use filters to focus. Active and Monitoring are typically the most useful default chips selected.
