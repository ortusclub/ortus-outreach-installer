A MODAL — Fires once per session after Start

Mode-aware copy: CC+IC tips below. localStorage flag silences after "Don't show again." Dismissable via the GOT IT button or Esc key.

MODAL · STAGE
CAMPAIGN STARTED

YOU'RE LIVE. A FEW THINGS TO KNOW.

  • 💻 Keep the lid open. The bot needs the screen unlocked while sending. Close the lid and sending pauses — monitoring resumes when you reopen.
  • ⏰ 15-second heads-up before each check. You'll get a macOS notification + cockpit ⏰ line 15 s before every auto-check. Mute via System Settings → Notifications → Ortus if it gets noisy.
  • 🔁 Monitoring runs for 7 days. Once sending wraps, Ortus quietly re-checks LinkedIn every 15 min looking for new acceptances and firing the IC DM. The cockpit ring shows the next-check countdown.
  • ⛔ Two ways to stop. "Stop sending" halts new connects but keeps monitoring active. "Stop everything" ends both. Default favours stopping just sending.
  • 📋 Sheet column headers matter. Empty trailing columns can produce a stray {} chip in templates. We filter those now, but a typo like "first name " (trailing space) still breaks substitution silently.
  • 📞 Click "Bulk Check Connections" anytime in the cockpit to fire an off-schedule sweep + IC DMs. Useful if you don't want to wait the full 15 min cadence.

Implementation note: tip content lives in a single JS object/array. The modal renders the same source as the cockpit card. Substitution happens at render-time via a tiny templating helper that reads campaign.checkIntervalMinutes and campaign.monitoringUntil directly from the cockpit state — no duplicated copy between A and B.
