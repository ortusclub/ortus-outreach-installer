The Conductor dropdown on the right only appears for admins (normal accounts don't see it and only ever see their own campaigns). Below: the normal-user view, then the admin view for contrast.

How it behaves: click a type chip → the board instantly shows only that type across all rails (running / up next / done), and the counts update. All resets it. For admins, the Conductor dropdown narrows to one person's campaigns and can combine with a type chip (e.g. "Jeriannec · CC"). Normal accounts never see other people's campaigns or the Conductor control at all.
