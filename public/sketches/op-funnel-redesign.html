Fixes baked into both

1 · Readable time. 2026-06-23T13:37:19.712Z → 17 Jul 2026, 12:40 (London time). You can tell when a run happened, sorted newest-first.

2 · "Queued" is gone. Today a row is written Queued before the send, then flipped to Invited — if the send fails it sits Queued forever, which is what confused you. New model: a target is ✓ Invited (confirmed sent) or ✗ Failed (with a reason). No permanent limbo — and the run summary counts the failures for you.

3 · Account is always the real account. No more mixing Local Browser with emails — the column shows the LinkedIn account credited, every time.
