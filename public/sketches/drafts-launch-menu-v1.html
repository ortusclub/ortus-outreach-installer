What each option does (same across all variants):
  • Start a campaign → POST /api/campaign/queue-only. Idle → launches immediately. Running → 409 with explanation (one-at-a-time constraint).
  • Queue it → same endpoint, but the operator KNOWS they want to wait. Adds to back of queue regardless of current state.
  • Schedule it → opens a date/time picker, then POST /api/schedules with a cron expression for that specific moment.
  • Save as draft → no-op besides closing the wizard. Autosave already persisted everything. Returns to dashboard.
