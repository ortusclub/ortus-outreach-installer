A · Recommended RESUME · gold pill
Matches what the campaign actually does (picks up at 22/50, not 0/50). Gold treatment is consistent with the design-system rule "gold = Start CTA" — Resume is a Start. Already what the internal code calls it (campaign-row-resume). Click = one-shot resume, no modal.
Past1
B CONTINUE · gold pill
Softer / friendlier than Resume. Reads as "keep going from where we left off". Same accuracy. Trade-off: 8 chars vs Resume's 6 — pill is slightly wider, eats a bit of horizontal space on narrow rows.
Past1
C PICK UP · gold pill
Most literal description of what happens — "pick up where you left off". Quotas preserved is implicit in the verb. Trade-off: two-word label is unusual in a pro-tool UI and can read as informal.
Past1
D RUN AGAIN · gold pill
Direct, no ambiguity in plain English. Risk: implies starting from zero. The campaign actually preserves per-account counts (e.g. resumes at 22/50, not 0/50). Operator could be surprised when their daily limit doesn't reset.
Past1
E · Treatment RESUME · hairline (no gold)
Same label as A, but uses the standard hairline pill instead of gold. Reasoning: the gold-only-on-Start rule could be interpreted strictly — Start CTA in the wizard stays uniquely gold; past-row Resume is a softer affordance. Trade-off: visually demotes Resume, makes Resume + Edit feel equally weighted.
Past1
F · Treatment STOPPED ▸ RESUME (chip-as-button)
Combine state + action into the existing STOPPED chip. The chip becomes interactive: hover reveals the action, click resumes. One fewer pill in the row. Trade-off: less discoverable — operator has to learn that the chip is clickable. Also loses the "Edit then Start" path's symmetry (Edit is still a separate pill).

Behavior — same for every variant

Click on the new button = one-shot resume. No modal. The campaign reopens with the saved settings snapshot (sheet URL, templates, profile IDs, daily limit, sender mapping). Per-account counts are preserved so accounts pick up at 22/50, not 0/50.

Edit pill keeps its current behavior — pre-fills the wizard so you can tweak before starting. The existing two-option resume modal (resume-choice-modal) becomes redundant and can be removed.

The same label should probably also replace "Re-run with same settings" in the past-campaign details modal (public/index.html:1236) for consistency.
