Visual hierarchy plan (Active → Past)
  • Now Active / Monitoring — full J card: rounded, dot pattern, drop shadow, colored accent rail, large Bebas hero metric
  • Up Next — outlined blocks: no dot pattern, no shadow, no accent rail, smaller radii, monochrome (drag-deck pattern from variant C)
  • Past — lightest treatment: hairline dividers only (P-A / P-C) or fading stack (P-B), names default to gray, hover to brighten, reply rate is the only Bebas anchor

All three Past variants share the same red Stopped early treatment so the visual signal stays consistent if you decide to mix patterns. No invented fields — every value comes from the existing campaign data model (mode, name, finished date, sent, replies, reply rate %, stopped boolean).
