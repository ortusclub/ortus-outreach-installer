How this works in Sheets: Apps Script SpreadsheetApp.getUi().showSidebar(HtmlService.createHtmlOutput(...)) docks an HTML panel on the right (320px wide). An onSelectionChange trigger detects the active row and the sidebar re-renders for that lead.
The grid stays as plain Sheets columns (Name / Stage / Sender) — minimal noise. All audit detail lives in the sidebar.
Action buttons in the sidebar fire Apps Script functions: open LinkedIn URL in a new tab, write to the Status column, append a note row, etc.
Trade-off: only works inside Sheets desktop (the sidebar isn't great on mobile). But that's where the operator is anyway.
