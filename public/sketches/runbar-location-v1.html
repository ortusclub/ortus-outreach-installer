Runbar Location · 3 variants

Where does the bottom run-control bar live?
Sam's PR moves the runbar from "always pinned to the bottom of the screen" to "inside the Live Status section". Pause / Stop are no longer one-click-away from anywhere — operator has to scroll to Live Status. Three options to consider.

1Fixed-bottom (current v2.58)

Runbar pinned to the bottom of the viewport. Always visible regardless of which tab or section the operator is on. This is what v2.58.0 ships today.

2In Live Status section (Sam's PR)

Runbar moved inside the Live Status section. Scrolls with the page. Only visible when the operator is on Live Status. Other tabs (Dashboard / Drafts / Past / etc.) have no runbar.

3Hybrid · floating mini-runbar (only when off Live Status)

Full runbar lives inside the Live Status section (same as variant 2). But when the operator navigates anywhere else WHILE a campaign is running, a compact pill appears in the bottom-right corner with just identity + Pause + Stop. Click the pill → jump to Live Status. Idle state = no pill at all.

Pro: Best of both. Full controls live in Live Status (variant 2 pro). Critical Pause / Stop are still one-click reachable everywhere else.
Pro: Idle state has NO bar at all — dashboard reclaims the full 60px even more cleanly than variant 2.

Con: Most complex of the three. Extra state to manage (which tab the operator is on).
Con: Mini-pill is a new UI element to design and test. Could feel cluttered if the operator pins it in a corner that overlaps something else.
