POST AMP
POST AMPLIFICATION
mode = "post_amplification"
REACTS / COMMENTS SENDS DMS
MODAL · "AMPLIFICATION RUNNING."
  • 💻Keep the lid open. Each reaction + comment fires through the real LinkedIn feed — needs an unlocked screen.
  • 👍Reaction: 80% Like / 20% mix (Celebrate, Support, Insightful, Funny, Love). Each profile reacts once per post — reactions are idempotent on LinkedIn's side.
  • 💬Comments are per-profile. Whatever you typed in each account's comment box gets posted by that account. Comments are NOT idempotent — re-running fires another comment.
  • ⏱Profiles run sequentially with a 60–300 s gap between them. Total runtime ≈ (1–5 min) × (number of profiles).
  • ⛔One way to stop. Press "Stop Campaign". Profiles that already commented stay — reactions can't be unliked from here.
