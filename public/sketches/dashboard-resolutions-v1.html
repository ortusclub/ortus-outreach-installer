1.

Monitoring · mini-J

~50% the visual weight of Active

Active and Monitoring share the same J-card weight today, but they're not the same kind of state. Active is sending right now; Monitoring is a passive 7-day watch that ticks. The proposed mini-J keeps the design language (dot pattern, blue accent rail, dock pill) but shrinks the hero metric and folds everything into two lines instead of five grid rows. Same readability for the key fields, half the vertical footprint.

3.

This Week · shared design language

flatter cells · same vocabulary as the deck

Today the calendar uses 6px rounded kanban tiles with soft fills and shadows — its own visual idiom. Proposed: keep the 7-column grid but flatten the cell treatment to match the Up Next deck — transparent background, hairline outline, smaller radius (4px), no shadow. Today gets a subtle differentiator (small green dot next to the date) instead of a heavy ink border. Chips inside the cells lose the saturated green wash and use the same monochrome treatment as everywhere else.

5.

Eyebrow dots · only on live sections

reduce 3 colors to 2 states

Currently each section has its own dot semantics: green (Active), blue (Monitoring), gray (Up Next), none (Past). Three signals for what should be a binary "is this happening right now or not". Proposed rule: colored dot = actively running (green sending, blue monitoring). No dot = idle (queued or past). One simple mental model.

Only change: drop the gray dot from the Up Next showcase eyebrow. Everything else stays. Net effect — a dot in your peripheral vision always means "running right now", which is a stronger signal than the current "dot = some kind of section header".

Order of impact (highest first):
  • 1 — Monitoring mini-J: biggest vertical-space win, immediately reduces the page's top-heavy feel
  • 4 — Past collapsible: smallest CSS change, biggest perceived "shorter page" win
  • 3 — Calendar shared language: most visual-coherence improvement across the page
  • 2 — Up Next denser preview: more value per pixel, but needs more wizard plumbing for the new fields
  • 5 — Eyebrow dot: polish, two-character CSS change

Each is independent — pick any subset. Recommend tackling 1 + 4 + 5 first (all small wins), then 3, then 2 (which depends on having the queued-at timestamp + sheet name fields available, which the wizard collects but the queue array currently doesn't store).
