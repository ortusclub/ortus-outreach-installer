D · Console

terminal feel · brand-native · ascii progress

Leans into the Bugatti command-deck identity instead of fighting it. Mono type, key/value rows, ASCII progress bar. Stays rectangular by design — the visual interest comes from typography and the bracketed structure, not from rounding. Feels native to the app, not stamped on from a component library.

E · Editorial Hero

magazine spread · big bebas headline

The campaign name becomes the hero — 48px Bebas Neue, treated like an article title. Top and bottom hairline rules instead of a card. Stats sit below as a column of figures (Bebas numerals for weight). Most ambitious visual statement; works best if you're okay with each active campaign claiming a lot of vertical space.

F · Boarding Pass

perforated divider · irregular shape

Two-panel card with a perforated divider between info and controls — like a paper ticket stub. The notches cut into the top and bottom edge make the shape recognisably not-a-rectangle without using big radii. Controls side gets a subtle background tint to read as a separate panel.

G · Mission Control

modular tile grid · phantombuster-like

Closest to the PhantomBuster reference Sam shared. Each concern (identity, sent, accepted, replies, controls) gets its own mini-tile in a 5-column grid. Scales gracefully if you ever run more than one campaign in parallel — they'd stack as identical strips. The trade-off: each row takes more horizontal space.
