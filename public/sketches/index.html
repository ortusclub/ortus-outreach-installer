Dashboard v0.3 — Unified vocabulary
Same dashboard as v0.2 with the same functional moves (mini Monitoring, dense Up Next preview, calendar between Up Next and Past, collapsed Past, details panel on Active/Monitoring) — but the four competing visual languages get quieted down to one. Goal: scroll the whole page and feel one calm command surface, not five sections each yelling for attention.
