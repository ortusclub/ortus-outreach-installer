How this works in Sheets: bot writes both cells on every action. Last action ≈ free text ("Connect accepted · 2d ago"). Next action is one of a fixed set of values; conditional formatting paints background by value.
Why it's nice: sort by Next column → all your "Send DM" rows clump together; same for "Read & follow up". The operator never has to decode CC/OP/Message/InMail again.
What goes away from view: CC, OP, Message, InMail status text — moved to a hidden Audit Log tab. The Pipeline tab is just Lead + Last + Next.
