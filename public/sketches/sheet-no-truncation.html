Variant 3 Strategic widths — fit the common case, wrap the rare one

Best-of-both. Widen the status columns just enough to fit their common values without wrap ("Connection Request Sent" fits, "Already connected" fits). Keep names + dates narrow. Only the LinkedIn URL column wraps (it's always long). Sheet ends up ~1280px — fits a 13" laptop with minimal horizontal scroll, and 90% of rows stay at single-line height. No code changes Most rows are uniform single-line. Status text fully readable, no ellipsis on common values. Operator-friendly default. A "Still Pending (2026-05-17 11:46)" value in a "Connected" sheet would still need wrap or get clipped — but those rows are intentional alerts anyway.
