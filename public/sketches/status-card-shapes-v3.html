Translation note

what kept · what changed

The source card has four design elements that translate cleanly to Ortus: (1) the bookmark/ribbon shape pinned to the top edge, (2) a single dominant metric in display type, (3) integrated CTA inside the card surface, (4) a subtle texture across the background. What can't translate without breaking the brand: saturated gradient backgrounds (Ortus is monochrome — gold reserved for Start), 16px radii (Ortus uses 0 or 9999 — both versions below cheat to 8px the same way variants A/B did), and framer-motion entry animations (vanilla CSS hover lift instead).

H · Ink Showcase

dark surface · 21st.dev DNA translated

Dark ink surface with a hairline dot pattern (replaces the source's bright gradient + bright dots). Accent edge in green/blue (replaces the full gradient). Bookmark in white holds the mode glyph — strongest shape element from the source preserved. Hero metric in Bebas Neue at 56px. Integrated translucent Open button inside the surface. This is the boldest variant in the set — a dark card sitting on the light dashboard reads as a "showcase" panel.
