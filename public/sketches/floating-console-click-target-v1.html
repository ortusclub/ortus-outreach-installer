Floating console — what opens on click

Three variants of click behavior for the bottom-left pill. The pill itself is the same in all three; only the click target changes. Cockpit content shown is the real #cockpit-panel from public/index.html (progress ring, status tag, action line, Lead / Account / Mode meta, Sent today / Errors stats).
Variant 1 · Recommended
Scroll-to existing Live Status section
Click → smooth-scroll to #nav-status. The cockpit panel that already exists in the dashboard slides into view. Operator's existing mental model is preserved — same widget they've used since v2.8.x. No new surface, no overlay, no duplication of state.
Cost · ~30 LOC · one new helper, calls existing scrollToSection()
