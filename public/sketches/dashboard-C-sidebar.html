FIX 1 — MONITORING TOP-LEVEL

Sidebar makes every state a peer. Counts are always visible — "Monitoring 3" sits next to "Active 1" so you see the full picture without scrolling.

FIX 2 — KEYBOARD-FIRST

⌘+A selects all in current list, Delete removes them. Sidebar persists when switching tabs so context is preserved — useful when bouncing between Past and Monitoring.

TRADE-OFF

Most "app-like" feel — closer to Linear / Notion than to the current page. Slightly wider browser window needed (sidebar uses ~240px). Best if the dashboard is used heavily multiple times a day.
