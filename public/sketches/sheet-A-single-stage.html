How this works in Sheets: Stage column is a Data → Data validation dropdown with the 7 fixed values. Color comes from Format → Conditional formatting rules — one rule per value, exact text match. The bot writes the value, Sheets paints the color automatically.
Filtering: click the column-G filter chevron, tick "Connected · DM Now" or "Replied" to focus on the rows that need you.
What goes away: the CC, OP, Message, InMail status text — those become side audit columns (kept for reference but you stop having to read them).
