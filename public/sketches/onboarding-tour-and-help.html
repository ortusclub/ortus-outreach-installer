GETTING STARTED

Five sections in the wizard. Each does one thing. Skim this once and you'll know where everything lives. Each section below mirrors what the interactive tour shows you, so you can come back here later if you forget.

I
CAMPAIGN TYPE
PICK WHAT YOUR CAMPAIGN DOES
[ SCREENSHOT · Section I — Mode dropdown + description ]
Choose the action this campaign performs. Connect requests, follow-up DMs, 3-way intros, InMail, Open Profile messages, or background checks. Each has different rules — they're explained in the launch modal that fires when you press Start.
  • 1The dropdown surfaces only modes available for your sheet (some require specific columns).
  • 2Switching modes hides/shows the right Settings sub-sections below.
II
DATA
YOUR GOOGLE SHEET
[ SCREENSHOT · Section II — Sheet URL input + tab hint ]
Paste the full Google Sheet URL — including the #gid=... tab if the sheet has multiple tabs. Ortus reads rows from this sheet and writes back the Stage column. The LinkedIn URL column is auto-detected if it's named LinkedIn URL.
  • 1Sheet must be shared with the Apps Script account (Ortus's Google account).
  • 2Column header typos with trailing spaces silently break variable substitution.
III
LINKEDIN ACCOUNTS
WHO SENDS
[ SCREENSHOT · Section III — Account chips + status badges ]
Select GoLogin profiles to use. Multiple accounts rotate through the lead list — throughput scales with accounts. Each chip shows the account's status (active, parked, weekly-limited, needs login) so you know which ones are healthy before launch.
  • 1Click any account to open its browser and re-auth if LinkedIn logged it out.
  • 2Parked accounts auto-rejoin on the next campaign or after manual "Retry".
IV
CAMPAIGN SETTINGS
TEMPLATES · PACING · TRACKING
[ SCREENSHOT · Section IV — Templates with variable chips ]
Write the message templates. Variable chips substitute from sheet columns at send time — click a chip to insert it at the cursor. Daily limit + pacing live here for CC modes (other modes have no daily cap). For CC+IC: Acceptance Tracking window and auto-check cadence.
  • 1Hover any chip to preview what it'll resolve to for the first row of your sheet.
  • 2Connect notes have a 200-character LinkedIn limit; counter is shown live.
V
LAUNCH
NAME · START · MONITOR
[ SCREENSHOT · Section V — Campaign name input + Start button ]
Give the campaign a name (used in the dashboard later) and press Start. The cockpit takes over: live progress, account queue, log, and the mode-specific tips card in the right column. A modal fires once explaining the things to know about this mode.
  • 1Campaign name supports the same placeholder syntax — e.g. TAG_CITY_I.
  • 2Once Start is pressed, the wizard collapses and the Live Status section expands.
VI
AFTER LAUNCH
LIVE STATUS · TIPS · STOP
[ SCREENSHOT · Live Status panel with sidebar tips card ]
The cockpit shows live state. The right-column tips card carries one-liner reminders specific to the running mode. "Bulk Check Connections" fires an off-schedule acceptance sweep. Pressing "Stop Campaign" opens the right modal for the current mode (Stop vs. End Monitoring vs. CC+IC two-way stop).
  • 1Closing the laptop lid pauses sending — sends resume when you reopen.
  • 2Live Status survives app restart for CC+IC monitoring runs (state persists to disk).

SUMMARY

Tour spotlight + callouts on the real wizard DOM (~200 lines of CSS+JS). Sidebar Help popover with 3 items. Static help page (public/help.html) mirrors the tour content with screenshot placeholders + a Replay button. First-launch trigger auto-fires; after the operator finishes or skips once, localStorage.ortusTourCompleted = '1' silences it.
