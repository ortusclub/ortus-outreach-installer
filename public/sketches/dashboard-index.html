DASHBOARD REDESIGN · 5 ALTERNATIVES · 2026-05-18

Five ways to lay this out

The current dashboard has five stacked sections (Active, Queued, Schedules, Drafts, Past) where Monitoring campaigns are buried inside Past — even though they're still actively running. Bulk delete exists but is hidden behind a small trash-icon toggle on the Past section header. These five sketches fix both, each with a different organizing principle.

PROBLEMS TO FIX

1. Monitoring campaigns appear in "Past" but they're still running. They need their own home.

2. Deleting multiple campaigns is painful — has to be done one at a time unless you find the small trash-toggle button.

CONSTRAINTS

Bugatti command-deck design system — monochrome, hairline borders, gold on key CTAs only. Vanilla HTML/CSS/JS (no React). Must work in the Electron shell at ≥1100px wide.

ALTERNATIVE A

Status sections + always-on select

Stacked sections (Active / Monitoring / Queued / Drafts / Past), each row has a tiny check column always visible. Closest to today's layout.

ALTERNATIVE B

Tabbed views

Five tabs at the top — pick one, the page becomes that list. Bulk-select toolbar always visible. Per-tab search.

ALTERNATIVE C

Sidebar nav (mailbox-style)

Left sidebar with categories and counts (like Gmail folders). Right pane = active list. Most "app-like".

ALTERNATIVE D

Unified list + filter chips

One table. Status chips at top act as filters (toggle multiple). Most flexible for bulk operations across states.

ALTERNATIVE E

Status lanes (kanban-style)

Four horizontal lanes (NOW → WATCHING → QUEUE → DONE). Cards in each lane have a small checkbox top-right. Visual lifecycle — campaigns literally flow left to right.

QUICK READ

If you mostly care about minimum disruption: A. If you spend most of your time in one section at a time: B. If you check the dashboard often and want counts always visible: C. If you bulk-edit a lot and want one unified table: D. If you want the most visually-distinct lifecycle view: E.
