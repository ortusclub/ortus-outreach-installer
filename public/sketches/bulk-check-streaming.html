BULK CHECK STREAMING — IN-PANEL FIT

Three drop-in panels for the area below BULK CHECK CONNECTIONS in the Live Status pane. Each variant uses the cockpit's actual tokens (Bebas Neue display, Hanken Grotesk mono labels, gold accent, hairline borders, monochrome) so the sketch is one-to-one with what would ship. All three replace the plain 📡 Manual bulk Connection Status check — sweeping 3 account(s)… text dump with a structured panel. The final-result card from commit 1ae7af4 stays; these only redesign the in-flight phase.

VARIANT A STAT STRIP + DOING-LINE

Three numeric stats above one italic line that names the account currently sweeping. Numbers tick up live as accounts finish. Thin gold progress bar at the bottom (N of M done). Same surface stays visible after the sweep completes — the numbers freeze, the doing-line is replaced by "completed in Ns" and the pill changes to DONE. PROS · smallest vertical footprint (~110px). Numbers identical to the final card so the surface feels continuous from in-flight → done. CONS · loses per-account detail while running — operator sees only one name at a time.

VARIANT B REUSE THE ACCOUNT QUEUE PATTERN

The same numbered row pattern the Live Status pane already uses for ACCOUNT QUEUE, repurposed as the bulk-check progress display. The right-side status pill animates through QUEUED → SWEEPING → DONE. Once each account finishes, its row shows the per-account result (e.g. "2 CONNECTED · 7 PENDING"). A header line above the rows carries the running totals. PROS · zero new visual vocabulary — feels native to the panel. Operator sees per-account contribution AND can spot a stuck or failed account at a glance. CONS · taller (~ 180-220px for 3 accounts). No big display numbers — the totals are inline text in the header.

VARIANT C MINI MONITORING CARD (LEFT-HAND ECHO)

Echoes the existing "MONITORING / WATCHING FOR ACCEPTANCES" card layout: a dashed circular indicator on the left (here used as a progress ring — N of M done), and key/value rows on the right. Reuses the exact card structure the operator already learned for the monitoring state, just with bulk-check semantics. The same surface flips to the final result when the sweep completes — the ring becomes a solid-line "DONE" badge. PROS · maximum visual continuity with the existing Live Status card. Big display number is prominent (matches "3M NEXT CHECK" treatment). No new component to learn. CONS · per-account detail is missing (same as A). The ring's progress-fraction meaning differs from the monitoring ring's time-remaining meaning — could confuse a quick reader.
