Four ways to make this section understandable at a glance. Today's labels ("Gap between leads within a batch (min, sec) — Floor 15s recommended") are technically accurate but operationally opaque — operators have to mentally translate. All four concepts ship the SAME underlying knobs (batches/hour, min/max pause); they just frame them differently.

C Throughput Dial one number — the rest auto-derives

Approach: the operator only specifies "How many leads per hour, per account". System derives batches and pause window automatically (with sensible defaults) and shows the breakdown. Hidden-by-default "Advanced" toggle reveals the underlying steppers if the operator wants fine control.

Trade-off: simplest mental model — most operators don't care about batches vs pauses, they just want X leads per hour. Loses fine-grained control unless Advanced is opened. Need to commit to a derivation rule (e.g. "leads/hour ÷ 5 = batches/hour, pause = 3600/leads ± 50%").
