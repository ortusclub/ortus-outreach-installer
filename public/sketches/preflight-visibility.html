Primary handshake — making the pre-flight visible

Three ways to surface the new pre-flight step (senders connect → primary accepts → outreach starts) on the dashboard, all built from the real vj-card components. Proposed new state = a gold "pre-flight" accent (green = running, blue = monitoring, gold = preparing). Pick a direction and I'll spec it.

Variant A
Minimal — same card, "Preparing" state + live beat

No new component. The normal campaign card opens in a gold "preparing introductions" state with a live activity line and a 2-step progress bar; the detail is in the live log. Lowest effort, lowest footprint.

Variant B
Dedicated pre-flight card — stepper + per-account checklist

A temporary gold card that owns the handshake: a Send → Accept → Start stepper plus a row per account, then it disappears and the normal running card takes over. Most explicit — you see exactly what's happening and which account is where.

Variant C
Integrated — phase chip + checklist + live log in one card

The campaign card itself, with a gold "PRE-FLIGHT" chip, the progress bar tracking the handshake, a compact checklist, and the real live log streaming the beats. Once done it morphs straight into the running card. Balanced — visible without adding a second card.
