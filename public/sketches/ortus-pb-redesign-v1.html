Ortus Outreach — PB-Inspired redesign

Single-page assembled redesign. Workspace landing with stats banner + filter chip row + campaign list, Campaign wizard restyled into PB-style cards (sections I–VI), Right-rail Console drawer for live status, Bottom dock with always-on engine state.
Real data fields only — all counts, names, modes, account avatars match what's in /api/campaign/status, MODE_LIST, GoLogin profile list, and the dashboard state buckets (active / queued / scheduled / monitoring / drafts / past). Multi-campaign visuals elsewhere in PB are not used — Ortus is single-campaign per project constraint.
