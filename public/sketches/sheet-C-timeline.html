How this works in Sheets: bot writes YYYY-MM-DD (or =TODAY()) to the appropriate stage column when each event happens. Conditional formatting on each column uses Format → Conditional formatting → Custom formula like =AND($D2<>"", TODAY()-$D2<7) to color recency.
Trade-off: wider sheet (6 stage columns vs 1 Stage column in idea A). But the shape of a row tells you instantly where the lead is — no reading required.
Filter recipe: "rows with Connect Sent but no Accepted yet" → filter Connect Sent NOT empty AND Accepted empty.
