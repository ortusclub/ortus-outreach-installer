Sheet Visual Cleanup

Four variants for cleaning up the operator-facing Google Sheet. Same data, same columns, same campaign behaviour — only the conditional-formatting rules and column widths change. Each variant calls out whether it touches Apps Script (column hiding) or is pure spreadsheet formatting.

Per the operator rule: sheet mockups use only what Google Sheets can actually do — cell background colors, hairline borders, font weight, font color, alignment. No HTML pills, cards, rounded corners, or shadows.

Today Current sheet — saturated, all-bold

Heavy yellow + green fills, bold text on every status cell, three near-identical status columns (Stage, Connection Request Status, Connection Accepted Status). Each row reads like a stripe of competing pills.

Variant B Stage-only — hide redundant status columns

Stage is the v2 source of truth. Connection Request Status, Connection Accepted Status, and Introduction Status are derived from it. Hide those three columns; let Stage carry all the meaning. Bot still writes to all columns — they're just hidden, exactly like prepareSheet already hides mode-irrelevant columns today. 1-line Apps Script change Massive reduction in visual noise — 7 columns instead of 10. Stage's text already captures everything ("Already connected" / "Connect Pending" / "Connected"). Operator sees one status, not three. If a step ever needs to inspect Connection Accepted Status's "Still Pending (timestamp)" line at a glance, they have to unhide the column. Mitigation: keep the column unhidden during active monitoring, hide once stamped.

Variant C Symbol prefix — no cell fill at all

Zero cell backgrounds. Status meaning carried by a single Unicode glyph at the start of the cell — ● green for done, ◐ amber for pending, ○ gray for empty/not-applicable. Quietest variant. Reads like a clean text document instead of a heat-map. No code changes Most calm. Print-friendly. Status still readable at scan-speed via the dot colour. Works at any zoom. Loses the colour-block scan — you can't see "everything that's pending" by squinting across the sheet anymore. Trade-off: less heat-map, more text density.
