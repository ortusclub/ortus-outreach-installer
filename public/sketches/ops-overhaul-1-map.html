Where that message should appear — and why it doesn't

If the "Hello Colleen…" message was sent by the automation, it would be one Operations Log row, on the tab for whoever ran Kyra's account:

TimestampOperatorSevOrtus AccountEventLead URL
2026-06-11 17:19Z??? (this is what you want)INFOKyra Dela CruzAuto-DM / Intro sent/in/colleen-…

It isn't there because the Operations Log froze on June 10. The Operator column on that row is the answer to "who did it." Restore the log → every future send is attributable. (And the two new primary-side actions above need to start writing to it too.)

Takeaway for the overhaul: the data model is already right — the Operations Log carries Operator + Account on every event. Two things are wrong: (1) the storage design ("one tab per campaign") collapses under scale and froze the log; (2) the new primary-side actions don't write to it yet. The fix sketch addresses both.
