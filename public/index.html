    Stop Campaign?

    All running browsers will be force-closed and the current run will end. Any leads already sent today are saved — leads in progress will roll back to "not attempted".

    End Monitoring?

    The 7-day acceptance watch will end. Any still-pending leads will be stamped Closed - Not Connected in the sheet. The campaign moves to the Past list.

    ⚠ Recovery action

    Force-restart the campaign engine?

    Use this when something is stuck and Stop / Pause aren't responding. Below is exactly what happens. Your progress on already-processed leads is safe — Restore reads the same on-disk ledger any campaign would.

    Kill Every running Orbita / Chromium / local-browser process
    Reset All in-memory campaign state — counters, parked profiles, soft warnings, queue cursors
    Preserve The on-disk ledger of which leads were already processed (state.json)
    Restart The same campaign, seeded with today's per-account counts
