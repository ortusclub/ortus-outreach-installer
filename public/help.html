GETTING STARTED

Seven sections in the wizard. Each does one thing. Skim this once and you'll know where everything lives. Each section below mirrors what the interactive tour shows you in-app, so you can come back here later if you forget.

I
CAMPAIGN NAME
The label that follows your campaign
[ SCREENSHOT · Campaign Name input at the top ]
The first thing at the top of the wizard. Give the campaign a name so you can find it in the dashboard later. Supports a placeholder convention — e.g. TAG_CITY_I if you run a lot of campaigns and want a naming pattern.
  • 1Persisted to localStorage as a draft, so you don't lose it if you refresh.
  • 2Optional — leave blank and the dashboard shows "Add name" inline-editable.
II
CAMPAIGN TYPE
Pick what your campaign does
[ SCREENSHOT · Section 1 — Mode dropdown ]
Choose the action this campaign performs. Connect requests, follow-up DMs, 3-way intros, InMail, Open Profile messages, or background checks (Check Status / Check DMs). Each has different rules — the launch modal that fires when you press Start explains the mode's specifics.
  • 1The dropdown surfaces only modes available for your sheet schema (some require specific columns).
  • 2Switching modes hides/shows the right Settings sub-sections below.
III
DATA
Your Google Sheet
[ SCREENSHOT · Section 2 — Sheet URL input + tab hint ]
Paste the full Google Sheet URL — including the #gid=... tab if the sheet has multiple tabs. Ortus reads rows from this sheet and writes back the Stage column. The LinkedIn URL column is auto-detected if it's named LinkedIn URL; otherwise pick it from the column dropdown that appears after the URL is recognised.
  • 1Sheet must be shared with the Apps Script Google account that runs the writebacks.
  • 2Column header typos with trailing spaces (e.g. "first name ") silently break variable substitution.
IV
LINKEDIN ACCOUNTS
Who sends
[ SCREENSHOT · Section 3 — Account chips + status badges ]
Select GoLogin profiles to use. Multiple accounts rotate through the lead list — throughput scales with accounts. Each chip shows the account's status (active, parked, weekly-limited, needs login) so you know which ones are healthy before launch.
  • 1Click any account to open its browser and re-auth if LinkedIn logged it out.
  • 2Parked accounts auto-rejoin on the next campaign or after manual "Retry".
V
THROUGHPUT & PACING
How fast Ortus sends
[ SCREENSHOT · Section 4 — Daily limit + delay sliders ]
Sits between Accounts and Templates. Sets the per-send pace (default 15–45 s) and, for Connect modes only, the daily limit per profile (default 50). Other modes (DM, IB, InMail, Open Profile) have no daily cap — they send to every eligible row.
  • 1Faster pacing = more throughput per hour, but raises LinkedIn risk on Connect modes.
  • 2The pace applies between sends within a profile; profiles still rotate independently.
VI
MESSAGE TEMPLATES
What gets sent
[ SCREENSHOT · Section 5 — Templates with variable chips ]
Write the connection note, follow-up DM, intro body, InMail subject + body, or Open Profile DM — whichever applies to the mode you picked. Variable chips substitute from sheet columns at send time — click a chip to insert it at the cursor. For Connect + Introduce Back: the Acceptance Tracking window (7 days) and the auto-check cadence (15 / 30 / 60 / 90 / 120 / 180 / 360 min — default 60) live here too.
  • 1Hover any chip to preview what it'll resolve to for the first row of your sheet.
  • 2Connect notes have a 200-character LinkedIn limit; counter is shown live.
VII
LAUNCH
Press Start
[ SCREENSHOT · Section 6 — Start button ]
Press Start. The cockpit takes over: live progress, account queue, log, and the mode-specific tips card in the right column. A modal fires once explaining the things to know about the mode you launched.
  • 1Once Start is pressed, the wizard collapses and Live Status expands automatically.
  • 2If another campaign is already running, this one gets queued — the wizard banner says so.
VIII
AFTER LAUNCH
Live Status · tips · stop
[ SCREENSHOT · Live Status panel with sidebar tips card ]
The cockpit shows live state. The right-column tips card carries one-liner reminders specific to the running mode. "Bulk Check Connections" fires an off-schedule acceptance sweep. Pressing "Stop Campaign" opens the right modal for the current mode (Stop vs. End Monitoring vs. CC+IC two-way stop).
  • 1Closing the laptop lid pauses sending — sends resume when you reopen.
  • 2Live Status survives app restart for CC+IC monitoring runs (state persists to disk).
